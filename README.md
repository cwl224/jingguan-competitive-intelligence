# 镜观 Agent 竞品分析系统

本仓库包含产品需求文档、已完成的前端和与之对接的 FastAPI 后端。模块二覆盖多类型数据采集，模块三覆盖任务调度与 Agent 编排，模块四覆盖数据清洗与信息抽取，模块五覆盖数据与知识存储，模块六覆盖检索与 RAG，模块七覆盖竞品分析 Agent。

## 目录

- `Agent竞品分析系统_产品需求文档_V1.0_最终版.docx`：产品需求依据
- `frontend/`：Vinext + React 工作台
- `backend/`：FastAPI + SQLite API 服务

## 启动后端

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

API 文档：`http://127.0.0.1:8000/docs`

## 启动前端

另开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

前端开发服务器会把 `/api` 自动代理到 FastAPI。首次启动后端会创建本地 SQLite 数据库并填充与工作台一致的演示数据。

## 模块二：数据采集

- 数据源启用前检查：授权状态、条款/robots 确认、速率上限和字段映射
- 采集执行：立即、计划和重试任务，统一状态、请求摘要、解析步骤与错误记录
- 采集器：静态 HTML、浏览器渲染动态页面、RSS/Atom、只读 JSON API、TXT/Markdown/HTML/JSON/CSV/XML/PDF/DOCX/XLSX/常见图片
- 数据留存：原始响应/文件、可读正文、元数据、结构化字段、SHA-256 内容指纹和 URL 版本链
- 安全边界：默认阻止内网/本机地址、限制响应体积、只允许 API GET、不绕过登录/验证码/付费墙或 robots 禁止规则

动态网页连接器默认调用本机 Microsoft Edge；如果部署机没有可用浏览器，可执行 `python -m playwright install chromium` 安装 Chromium。

## 模块三：任务调度与 Agent 编排

- 定时、立即、事件与 API 触发，按来源优先级和可执行时间派发
- 任务级超时、单来源速率/并发限制，以及可配置的指数退避重试
- 采集 Agent、内容理解 Agent、去重 Agent、质量 Agent 四阶段工作流状态
- 七类任务终态、节点耗时与错误上下文、异常队列和批量重试
- 连续失败自动熔断，人工恢复进入半开试探，成功后自动闭合
- 服务重启自动识别被中断任务，未耗尽重试的任务重新排队补采

## 模块四：数据清洗与信息抽取

- 从 HTML 语义节点或采集可读层提取正文，移除导航、广告、版权、Cookie 提示和重复行
- 识别中文、英文、日文和韩文；图片及无文本扫描 PDF 可调用 Tesseract OCR
- 在项目内执行跨来源精确/近似去重，保留重复簇、匹配材料和相似度
- 抽取企业、品牌、产品、人物、版本、价格、地点、日期和功能实体
- 抽取发布、价格变化、合作、融资、收购、市场进退、功能变化和招聘事件
- 每个实体/事件保存原文位置、抽取方式与置信度；低质量或 OCR 异常结果进入人工复核
- 原始快照只读，重新处理只更新独立的处理结果层

## 模块五：数据与知识存储

- 三层持久化：原始快照与哈希版本链、独立处理结果、事实/实体/事件/洞察知识索引
- 处理完成后自动把材料事实、实体和事件写入知识库，并保留文档、来源、原文位置、方法与置信度
- 按关键词、知识类型、复核状态和专题集合组合检索
- 证据链下钻可查看来源授权、保留期限、材料版本、内容哈希、解析版本和原文片段
- 支持已核验、待复核和来源冲突状态，所有人工状态变更保留版本与审计记录
- 支持创建专题集合、加入或移出知识条目，集合可直接作为后续报告选材范围

## 模块六：检索与 RAG

- 在项目、授权状态、有效期、竞品、知识类型、复核状态、专题集合和时间范围内过滤候选知识
- 对中文与英文查询执行词项扩展、字段加权、置信度与复核状态重排
- 仅从命中知识中抽取回答，逐条绑定来源与原文证据；证据不足时拒绝补写
- 显示数据截止时间、综合置信度、召回数量、风险提示和完整检索轨迹
- 查询、召回知识 ID、过滤条件和生成模式写入审计日志

## 模块七：竞品分析 Agent

- 分析规划、检索、证据校验、竞品分析与策略五个 Agent 步骤
- 支持选择 2–8 家竞品、六类对比维度和 7/30/90 天或全部时间窗口
- 输出证据化对比矩阵、事实/推断分层发现、SWOT 和商业建议
- 缺失数据明确显示“暂无可信数据”，不会自动推断竞争劣势
- 分析结果、引用、覆盖率、样本量、Agent 轨迹与历史版本持久化

## 模块八：报告、订阅与预警

- 内置日报、周报、产品对比、竞品快讯、专题研究和高管摘要模板
- 报告生成保留数据截止时间、版本、证据数、来源数、置信度和审批轨迹
- 支持在线阅读、审批/退回以及真实 Word/PDF 文件导出
- 报告订阅支持周期、时区、收件人、应用内/邮件/企业消息渠道和启停控制
- 预警规则支持竞品、关键词、事件、影响等级、置信度、变化幅度、静默期与升级时限
- 重复信号自动合并，预警可确认、处置和关闭，所有动作进入审计日志

## 模块九：管理、安全与运维

- 组织、成员、角色、项目范围、数据域、MFA 和导出权限的 RBAC 管理
- SSO、会话、高敏导出、数据保留、个人信息和敏感模型路由策略门禁
- 模型供应商、版本、数据分类、预算配额、告警阈值和降级模型配置
- 黄金集评测展示准确率、引用完整度、拒答率、延迟、成本和样本量
- 登录/配置/采集/报告/预警/模型/备份等操作的统一审计查询
- 生产接口使用签名 Bearer Token，并按角色、项目范围和数据域逐层授权；开发环境保留可关闭的本地用户兼容入口
- 数据源普通删除采用可审计归档，历史运行、原始材料与证据继续保留；永久清除仅向管理员开放并要求精确二次确认
- 服务健康、事故确认/关闭、RPO/RTO、增量备份与恢复校验
